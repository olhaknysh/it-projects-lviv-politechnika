# Multi-City Timeline 🌍✈️

**Multi-City Timeline** — це адаптивний фронтенд-додаток (MVP) для планування насичених подорожей, що включають переїзди між кількома містами. Замість хаотичних нотаток у телефоні та розрізнених скріншотів бронювань, додаток збирає всю поїздку в єдину, інтуїтивно зрозумілу хронологічну стрічку (таймлайн).

> 💡 **Ідея MVP:** Дати мандрівнику чітку візуальну картину кожного дня поїздки: від часу виїзду з одного міста до чек-іну в готелі та часу початку екскурсії чи оренди транспорту в іншому.

---

## 🛠️ Технологічний стек

*   **Frontend:** JavaScript (ES6+)
*   **Компоненти та Логіка:** Vite

---

## 📂 Структура проєкту (Базова)

├── index.html                  # Головна точка входу для Vite (у корені)
├── package.json                # Конфігурація проєкту та скрипти Vite
├── .gitignore                  # Налаштування ігнорування файлів Git
├── public/                     # Статичні ресурси, які не обробляє Vite (напр., favicon.ico)
└── src/                        # Весь вихідний код додатка
    ├── main.js                 # Точка входу в JavaScript (підключається в index.html)
    ├── assets/                 # Глобальні стилі, зображення
    ├── components/             # Перевикористовувані UI-компоненти (кнопки, модалки)
    ├── features/               # Основні функціональні модулі
    │   ├── dashboard/          # Головний екран (список усіх турів)
    │   └── timeline/           # Екран поточної подорожі (стрічка днів)
    ├── services/               # Робота з даними (модуль збереження в LocalStorage)
    └── utils/                  # Допоміжні функції (форматування дат, валідація часу)

## 📂 Інструкція по запуску

npm install

npm run dev
